## 💻 Getting Started Locally

### Option 1: Direct Browser Launch
Double-click `index.html` in your file explorer or open it directly in Google Chrome, Microsoft Edge, or Mozilla Firefox.

### Option 2: Local HTTP Server (Python)
If Python is installed on your system:
```bash
# Navigate to the project directory
cd c:\Users\DELL\shreya

# Start a local HTTP server on port 3000
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your web browser.

### Option 3: Node / NPX
```bash
npx serve ./
```
